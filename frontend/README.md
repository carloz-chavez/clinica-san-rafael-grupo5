# Frontend

Carpeta reservada para el proyecto React + Vite (tarea G1, responsable: Gonzalo).

Estructura prevista dentro de `src/`:

```
api/            Cliente de la API (agrega el token y traduce errores)
autenticacion/  Contexto de sesión y rutas protegidas
componentes/    Boton, Campo, Selector, Tabla, Modal, InsigniaEstado, Alerta
diseno/         Menú lateral por rol y estructura general
paginas/        InicioSesion, GestionPacientes, AgendaCitas, HistoriaClinica
utilidades/     Funciones auxiliares
```

Para crear el proyecto dentro de esta carpeta: `npm create vite@latest . -- --template react` y elegir "ignorar archivos y continuar" si pregunta por el contenido.
